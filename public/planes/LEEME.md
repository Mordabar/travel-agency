# Fotografías de los planes

Coloca aquí las imágenes reales de cada plan (JPG o WebP, lado largo ≈ 1600 px).
Después referencia la ruta en `src/content.js`, dentro del plan correspondiente:

```js
{ id: 'cartagena-4d', name: '...', image: '/planes/cartagena-4d.jpg' }
```

Mientras un plan no tenga imagen, la galería 3D usa una ilustración generada
por código. Nunca se usa banco de imágenes genérico.
